# 公司模型集成边界

- `config.ts`：环境变量、连接协议和客户端归属配置；只在调用时读取配置，不访问数据库。
- `responses-client.ts`：Responses HTTP 请求、JSON 输出约束、响应提取、取消与超时；不承载需求、回归或浏览器动作提示词。
- 业务模块负责自己的提示词、输入输出校验和版本记录，通过上述客户端调用模型。固定规划、动态决策、用例设计、变更分析及评估复用此处，不复制协议实现。

根目录 `model-client.ts` / `model-config.ts` 仅是旧路径兼容导出，保留给冻结的 `model.ts` 和既有外部调用；新增生产代码直接导入本目录。旧文件不是另一套实现，不应在其内新增业务逻辑。

本次目录归属不改变协议、默认配置、prompt、失败处理或评估成绩。配置密钥、真实模型输出和运行产物不属于源码，不提交。
