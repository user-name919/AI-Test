# 测试数据设计

用途：让用例表达数据选择策略，不把模型编造的示例值当作真实账号数据。

1. 先确定意图：完整搜索、部分关键词、无匹配负例、边界、枚举或状态转换，再选择数据来源。
2. 完整搜索使用真实可选项的完整名称；部分搜索使用其非空严格子串，保留来源选项和本次实际值。两者不能互换。
3. 无匹配负例需要说明候选范围是否完整。虚拟列表、分页、远程检索只凭可见项不能证明全局不存在，应使用可控夹具或标记待准备数据。
4. 人工值需要理由，夹具值需要存在性证据。未知账号的数据不能从需求示例直接固定下来。
5. 日期边界需明确时区、基准日期和可控时间来源；未给定时提问，不擅自按本地时间补齐。
6. 不因为数据不满足就放宽断言或换成更容易通过的数据；应保存受阻原因并交由人工处理。

输出必须遵循当前阶段已支持的策略 schema；尚未支持的策略报告为限制，不伪装成受支持策略。
